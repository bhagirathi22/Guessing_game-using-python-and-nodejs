# Number Guessing Game

Two command-line implementations of the same number guessing game, written in Python and Node.js.

## How to Play

The program chooses a random whole number from 1 to 100. Enter guesses until you find it. After each incorrect valid guess, the program tells you whether the guess was too high or too low. When you guess correctly, it prints the total number of valid attempts. Invalid input and numbers outside the range are not counted.

## Run the Python Version

```bash
python guessing_game.py
```

## Run the Node.js Version

```bash
node guessing_game.js
```
